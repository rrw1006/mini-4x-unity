# Mini 4X (Unity)

Civilization VI 스타일 시스템을 얹은 미니 4X 전략 게임 프로토타입입니다.
Unity 6 + 순수 C# 코드로 만들어졌으며, 전부 무료 도구/에셋으로 제작되었습니다.

## 주요 기능

- **탐험/확장/개발/정복(4X)**: 절차적으로 생성되는 맵(평지/숲/언덕/산/바다), 정착민으로 도시 건설, 유닛으로 전투
- **진짜 Fog of War**: 탐험한 지역(기억, 어둡게)과 실시간 시야(밝게)를 구분
- **도시 성장**: 인구/식량/주택/쾌적도/충성심을 관리하는 도시 시뮬레이션
- **특수 지구**: 캠퍼스·상업 허브·산업 구역 등 인접 보너스가 있는 구역 건설
- **기술/시민 트리**: 연구를 통해 새 유닛·건물·구역 해금
- **정부와 정책 카드**: 정부를 선택하고 정책 카드로 산출량 보정
- **불가사의, 황금기/암흑기, 위인**: 세계에 하나뿐인 불가사의 경쟁, 시대 평가, 위인 영입
- **도시국가**: 특사를 보내 종주국이 되면 매턴 보너스
- **무역로**: 무역상인 유닛으로 도시 간 무역로 개설
- **유닛**: 정착민, 전사, 궁수(원거리 공격), 기마병, 검사, 무역상인
- **생산 대기열 + 골드 즉시 완성(러시 바이)**
- **승리 조건**: 상대 전멸 또는 턴 150 도달 시 점수 승리

## 실행 방법

1. [Unity Hub](https://unity.com/download)에서 Unity **6000.3.21f1** 에디터 설치
2. Unity Hub → Open → 이 저장소 폴더 선택
3. 씬을 열고 Play 버튼 클릭 (게임이 코드로 자동 부트스트랩되므로 별도 씬 설정 불필요)
